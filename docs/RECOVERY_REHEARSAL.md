# Public recovery rehearsal

Anonymous mirror clone of seven allowlisted public pilot repositories, full Git fsck, bundle creation and validation, temporary mirror restore, exact ref comparison and default HEAD verification. Only an allowlisted JSON proof is uploaded. Bundles are destroyed at the end of each job. This is a real recovery rehearsal, not an independent retained backup. The private backend and durable encrypted backups remain outside this public workflow. LFS, issues, release assets and repository settings are not covered.
